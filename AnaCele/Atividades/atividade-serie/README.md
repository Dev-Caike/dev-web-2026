Pretty Little Liars

Sobre a atividade

Esta atividade foi desenvolvida como atividade de Desenvolvimento de Interface, utilizando HTML e Bootstrap.

A página apresenta informações sobre a série **Pretty Little Liars**, conhecida por seus mistérios, segredos e suspense.

Informações da série

- Título: Pretty Little Liars
- Ano de lançamento:** 2010
- Gênero: Suspense, drama e mistério
- Criadora: I. Marlene King
- Temporadas: 7

Sinopse

Após o desaparecimento de Alison DiLaurentis, quatro amigas começam a receber mensagens misteriosas de uma pessoa que se identifica como "A". Segredos começam a ser revelados e a vida das amigas nunca mais será a mesma.

Personagens principais

- Aria Montgomery: Interpretada por Lucy Hale.
- Spencer Hastings: Interpretada por Troian Bellisario.
- Hanna Marin: Interpretada por Ashley Benson.
- Emily Fields: Interpretada por Shay Mitchell.

Conteúdo da página

A página apresenta:

- Título e apresentação da série;
- Sinopse;
- Imagem de capa;
- Cards com as personagens principais;
- Breadcrumb para navegação;
- Carousel com imagens da série.


Tecnologias utilizadas

- HTML5
- Bootstrap 5
- CSS

Conceitos aplicados

- HTML semântico;
- Bootstrap via CDN;
- Layout responsivo com Grid;
- Componente Card;
- Componente Breadcrumb;
- Componente Carousel;
- Estilização com CSS.

Objetivo

Praticar os conceitos de HTML e Bootstrap aprendidos em sala de aula, utilizando componentes para desenvolver uma página web organizada e responsiva.
