Piratas do Caribe — A Maldição do Pérola Negra

Sobre a atividade

Esta atividade foi desenvolvida como atividade de Desenvolvimento de Interface, utilizando HTML e CSS.

A página apresenta informações sobre o filme "Piratas do Caribe: A Maldição do Pérola Negra", lançado em 2003.

Informações do filme

- Título: Piratas do Caribe: A Maldição do Pérola Negra
- Ano: 2003
- Gênero: Aventura e fantasia
- Diretor: Gore Verbinski
- Personagens principais: Jack Sparrow, Will Turner e Elizabeth Swann.

Conteúdo da página

A página apresenta

- Título do filme;
- Imagem da capa;
- Sinopse;
- Elenco principal;
- Informações sobre a direção.

Tecnologias utilizadas

- HTML
- CSS3

Conceitos aplicados

- HTML semântico;
- Organização dos elementos com Flexbox;
- Variáveis CSS utilizando;
- Estilização com CSS;
- Organização e espaçamento dos elementos;
- Responsividade.

Objetivo

Praticar os conceitos de HTML e CSS aprendidos em sala de aula, desenvolvendo uma página web organizada e visualmente agradável.
