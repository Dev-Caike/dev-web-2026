A Hora do Pesadelo 2: A Vingança de Freddy

 Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica da disciplina de Desenvolvimento de Interface Web, utilizando HTML e CSS.

A página apresenta informações sobre o filme A Hora do Pesadelo 2: A Vingança de Freddy, lançado em 1985.

Sobre o filme

- Título original: A Nightmare on Elm Street Part 2: Freddy's Revenge
- Ano: 1985
- Gênero: Terror
- Direção: Jack Sholder
- Personagem principal: Jesse Walsh
- Vilão: Freddy Krueger

Sinopse

Jesse Walsh se muda com sua família para uma casa na Rua Elm e começa a ter pesadelos assustadores com Freddy Krueger. Aos poucos, Freddy tenta tomar o controle de seu corpo para voltar a cometer seus crimes no mundo real.

 Tecnologias utilizadas

- HTML5
- CSS3


Objetivo

Praticar a criação de páginas web utilizando HTML semântico, estilização com CSS, organização de conteúdo e recursos de responsividade.


Projeto acadêmico – Desenvolvimento de Interface Web.
