# 3ª Avaliação: Página de Série - Breaking Bad

Projeto desenvolvido como parte da 3ª Avaliação da disciplina de Desenvolvimento de Interfaces. O objetivo é criar uma página web homenageando uma série de TV favorita (neste caso, *Breaking Bad*).

## Tecnologias Utilizadas
* **HTML5:** Utilizando tags semânticas para melhor estruturação e acessibilidade (`<header>`, `<main>`, `<section>`, `<footer>`, `<article>`, `<nav>`).
* **Bootstrap 5 (CDN):** Utilizado para estilização, layout responsivo via Grid e componentes de interface.

## Componentes Obrigatórios Implementados
1. **Breadcrumb:** Localizado no topo da página (dentro da tag `<nav>`), oferecendo uma navegação de contexto.
2. **Carousel:** Componente de destaque localizado no `<header>`, contendo 3 imagens (slides) temáticas da série.
3. **Cards:** Organizados em um Grid Responsivo na seção de elenco, exibindo imagem, nome do personagem, ator e uma breve descrição.

## Como Executar
1. Clone este repositório ou faça o download dos arquivos.
2. Dê um duplo clique no arquivo `index.html` para abri-lo em qualquer navegador web (é necessário ter conexão com a internet para carregar o CSS e JS do Bootstrap via CDN e as imagens placeholder).
