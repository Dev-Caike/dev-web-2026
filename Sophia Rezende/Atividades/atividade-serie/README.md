# 2ª Avaliação: Página de Série — Game of Thrones

Página web sobre a série **Game of Thrones**, feita com **HTML e Bootstrap **.
## Descrição

A página apresenta a série da HBO (2011 a 2019, 8 temporadas e 73 episódios), baseada nos livros de George R. R. Martin, com:

- **Destaques:** carrossel com imagens e informações da série.
- **Sobre a série:** sinopse e ficha técnica.
- **Elenco principal:** cards com foto, casa, descrição do personagem e nome do ator.

## Estrutura de arquivos

```
└── index.html   # página completa (HTML + Bootstrap)
```

## Paleta de cores

Baseada na paleta de "Game of Thrones" (cores como Lannister Gold, Brienne's Bravery, Ygritte's Locks, Castle Black, ...).
