# 📺 Página de Série: Shameless (US)

Projeto desenvolvido para a avaliação de **HTML5 Semântico & Bootstrap 5**, apresentando uma página informativa e responsiva dedicada à série **Shameless**, ambientada no *South Side* de Chicago.

---

## 📋 Sobre o Projeto

A página reúne os principais destaques da série **Shameless (2011–2021)**, incluindo sinopse, ficha técnica, fases das temporadas e os personagens centrais da família **Gallagher** (Fiona, Frank, Lip, Ian, Debbie e Carl).

### 🛠️ Tecnologias Utilizadas
* **HTML5 Semântico:** Estruturação completa utilizando `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`.
* **Bootstrap 5.3 (via CDN):** Layout responsivo com sistema de grid (`container`, `row`, `col`), classes utilitárias e componentes interativos.
* **Bootstrap Icons (via CDN):** Ícones para enriquecimento visual da interface.
* **CSS3 Customizado:** Estilização complementar para paleta temática, tipografia e transições nos cards.

---

## 🧩 Componentes Bootstrap Implementados

1. **Navbar Responsiva:** Barra de navegação fixa no topo com menu colapsável para dispositivos móveis e acesso rápido às seções.
2. **Breadcrumb:** Navegação de contexto no topo da página (`Início > Séries > Drama & Comédia Ácida > Shameless (US)`).
3. **Carousel:** Carrossel interativo com 3 slides de destaque, indicadores, controles de navegação e legendas descritivas.
4. **Cards:** Grid responsivo exibindo os 6 personagens principais da família Gallagher, com imagens, intérpretes, temporadas e descrições.
5. **Modal:** Janela interativa com o checklist de entrega e estrutura de pastas exigida no repositório.

## 🚀 Como Executar o Projeto

1. Clone ou baixe o repositório para a sua máquina.
2. Navegue até a pasta `seuNome/Atividades/atividade-serie/`.
3. Abra o arquivo **`index.html`** diretamente em qualquer navegador moderno (Chrome, Edge, Firefox) ou utilize a extensão **Live Server** no VS Code.
4. Não é necessária nenhuma instalação de dependências locais, pois o Bootstrap é carregado via CDN.
