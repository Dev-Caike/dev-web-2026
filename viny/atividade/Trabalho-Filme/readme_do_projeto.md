# 🏎️ Velozes e Furiosos 2 (2 Fast 2 Furious) — Página Web

Página web temática desenvolvida como atividade prática de Desenvolvimento Web, apresentando informações sobre o filme **Velozes e Furiosos 2 (2003)**, dirigido por John Singleton.

---

## 📋 Requisitos Atendidos

O projeto foi construído aplicando os conceitos solicitados em sala de aula:

- **HTML Semântico:** Uso estruturado das tags `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>` e `<footer>`.
- **Arquivo CSS Separado:** Estilização isolada no arquivo `estilo.css`, devidamente vinculado ao `index.html` por meio da tag `<link>`.
- **Variáveis CSS (`:root`):** Definição e aplicação de variáveis globais para paleta de cores, tipografia e espaçamentos.
- **Layout e Responsividade:** Organização visual utilizando **Flexbox**, **Grid** e componentes responsivos do **Bootstrap 5** (Navbar, Breadcrumb, Carousel, Cards e Modal), garantindo boa legibilidade em diferentes tamanhos de tela.
- **Conteúdo Completo:** Título do filme, sinopse, ficha técnica com direção, elenco principal e imagem de capa.

---

## 🗂️ Estrutura de Arquivos

```text
├── index.html      # Estrutura principal da página em HTML5 semântico
├── estilo.css      # Folha de estilos personalizada com variáveis no :root
├── capa.jpg        # Imagem de capa/pôster oficial do filme

```
