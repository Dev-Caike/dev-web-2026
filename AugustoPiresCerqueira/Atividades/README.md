# Página de Série: Brooklyn Nine-Nine

## Requisitos Implementados
- **HTML Semântico:** Uso estruturado das tags `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`.
- **Bootstrap 5 (CDN):** Grid responsivo (`row`, `col-*`), navbar, badges e classes utilitárias de espaçamento.
- **Breadcrumb:** Navegação contextual no topo da página (`Início > Séries de Comédia > Brooklyn Nine-Nine`).
- **Carousel:** Carrossel interativo com 3 slides de destaques da série.
- **Cards:** Exibição do elenco principal com título, ator/atriz, descrição e cargo.
