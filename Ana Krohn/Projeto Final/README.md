Páginas web desenvolvidas com foco em boas práticas de estruturação e estilização, apresentando informações detalhadas sobre o filme e série da minha escolha

## Tecnologias e Recursos Utilizados

- **HTML5 Semântico:** Utilização de tags estruturais apropriadas (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) para melhor acessibilidade e SEO.
- **CSS3 Modular:** Estilização separada em um arquivo dedicado (`estilo.css`).
- **Variáveis CSS (`:root`):** Centralização de cores, tipografia e espaçamentos para facilitar a manutenção do design.
- **Layout Flexível:** Organização de elementos construída com **Flexbox** e/ou **Grid**.

## Conteúdo da Página

- Título do filme
- Sinopse oficial
- Elenco principal
- Diretor
- Imagem de capa (pôster)

# Projeto Web: Página de Série

Página web dedicada a série que escolhi desenvolvida com foco em boas práticas de estruturação e estilização modular.

## Tecnologias e Recursos

- **HTML5 Semântico:** Estrutura completa utilizando tags como `<header>`, `<main>`, `<section>`, `<article>` e `<footer>`.
- **CSS3 Personalizado:** Estilização isolada em um arquivo dedicado (`estilo.css`).
- **Variáveis CSS (`:root`):** Padronização de cores, tipografia e espaçamentos no escopo global.
- **Layout Responsivo:** Organização de elementos construída com **Flexbox** e/ou **Grid**.
