# The Walking Dead - Página de Série

Projeto da **3ª Avaliação**: página sobre a minha série favorita usando HTML semântico e Bootstrap.

## O que tem na página

- **HTML semântico:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`
- **Bootstrap via CDN:** grid responsivo (`container`, `row`, `col-*`) e classes utilitárias (`py-4`, `mb-5`, `text-danger`...)
- **Card:** cards com os personagens principais e seus atores
- **Breadcrumb:** navegação de contexto no topo (Início > Séries > The Walking Dead)
- **Carousel:** carrossel com 3 slides de destaques da série
- **Conteúdo:** título, sinopse, elenco principal e imagens
