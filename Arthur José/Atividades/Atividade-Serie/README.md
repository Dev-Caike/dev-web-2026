# 3ª Avaliação – Página de Série (HTML & Bootstrap)

**Série escolhida:** Stranger Things

## Sobre o projeto
Página web sobre a série *Stranger Things* feita com HTML semântico e Bootstrap 5 (via CDN).

## Elementos utilizados
- **HTML semântico:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`.
- **Bootstrap via CDN:** grid responsivo (`container`, `row`, `col`, `row-cols-*`), navbar e classes utilitárias de espaçamento, cor e texto.
- **Card:** elenco principal (personagens) e temporadas da série.
- **Breadcrumb:** navegação de contexto no topo (Início > Séries > Stranger Things).
- **Carousel:** 3 slides com destaques da série, com indicadores e controles.
- **Conteúdo:** título, sinopse, elenco principal e imagens.

## Estrutura
```
├── index.html
├── README.md
└── images/
```

## Como executar
Abra o `index.html` no navegador (é necessária conexão com a internet para carregar o Bootstrap via CDN).

## Observação
As imagens são ilustrações genéricas; podem ser trocadas por imagens reais da série.
