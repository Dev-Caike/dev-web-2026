Super Máquina (Knight Rider)

Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica da disciplina de Desenvolvimento de Interface Web, utilizando HTML e Bootstrap.

A página apresenta informações sobre a série Super Máquina, conhecida originalmente como Knight Rider, exibida a partir de 1982.

Sobre a série

- Nome original: Knight Rider
- Nome no Brasil: Super Máquina
- Ano de estreia: 1982
- Gênero: Ação, aventura e ficção científica
- Criador: Glen A. Larson
- Ator principal: David Hasselhoff
- Temporadas: 4

 Sinopse

A série acompanha Michael Knight, um agente que combate o crime com a ajuda de KITT, um carro inteligente equipado com tecnologias avançadas. Juntos, eles enfrentam diversas missões e ajudam pessoas em situações de perigo.

Tecnologias utilizadas

- HTML5
- Bootstrap 5
- CSS3

Componentes Bootstrap utilizados

- Breadcrumb: para navegação da página.
- Card: para apresentação dos personagens.
- Carousel: para exibição de imagens da série.
- Grid: para organização dos elementos.
- Container: para estruturar o conteúdo.

Objetivo

Praticar o desenvolvimento de páginas web utilizando HTML, CSS e Bootstrap, explorando componentes prontos, organização de conteúdo e responsividade.


Projeto acadêmico – Desenvolvimento de Interface Web.
